Renovate setup (consumer repository)

Copy registry/renovate-example.json into your repository as renovate.json, or merge the relevant sections into an existing config. This repository uses the same settings in its root renovate.json to keep mc.html mod links up to date. 

{
  "extends": ["config:recommended", ":rebaseStalePrs"],
  "enabledManagers": ["custom.regex"],
  "customDatasources": {
    "clarissegilles-curseforge": {
      "defaultRegistryUrlTemplate": "https://clarissegilles.github.io/registry/{{packageName}}.json",
      "transformTemplates": ["$"]
    }
  },
  "customManagers": [
    {
      "customType": "regex",
      "managerFilePatterns": ["/mc\\.html$/"],
      "matchStrings": [
        "href=\"https://www\\.curseforge\\.com/minecraft/(?:modpacks|mc-mods)/(?[^/]+)/files/(?\\d+)\""
      ],
      "datasourceTemplate": "custom.clarissegilles-curseforge",
      "depNameTemplate": "1.21.1/neoforge/{{slug}}",
      "registryUrlTemplate": "https://clarissegilles.github.io/registry/1.21.1/neoforge/{{slug}}.json",
      "versioningTemplate": "loose"
    }
  ],
  "packageRules": [
    {
      "matchDatasources": ["custom.clarissegilles-curseforge"],
      "maxMajorIncrement": 0
    }
  ]
}

Point each regex manager at the registry JSON with registryUrlTemplate. Use versioning: loose and maxMajorIncrement: 0 because CurseForge file IDs are opaque integers, not semver.

Changelogs in Renovate PRs

The updater fetches CurseForge changelogs and writes them to changelogs/<version>/<loader>/<slug>/CHANGELOG.md in this repository. Each registry JSON exposes sourceUrl and sourceDirectory so Renovate can embed release notes in PRs.

Changelog sections use the CurseForge file ID as the heading, for example ## 8601207. View them on this page under Changelogs above.

Renovate needs at least two entries in each registry releases array (current and latest file ID) before it can embed collapsible release notes. The updater keeps prior releases instead of overwriting the array with only the newest file.

Adding or changing tracked mods

  1. Edit registry/config.json in this repository.
  2. Set slug, projectType (mod or modpack), modLoader, and gameVersion (prefix match, e.g. 1.20).
  3. Add a CURSEFORGE_API_KEY secret to the curseforge environment under Settings → Environments → curseforge (the name must match exactly).
  4. Run the Update CurseForge registry GitHub Action or wait for the scheduled refresh.

Response format

Each registry URL returns Renovate-compatible JSON:

{
  "sourceUrl": "https://github.com/ClarisseGilles/ClarisseGilles.github.io",
  "sourceDirectory": "changelogs/1.21.1/neoforge/distant-horizons",
  "releases": [
    {
      "version": "8389148",
      "releaseTimestamp": "2026-07-07T20:28:23.42Z",
      "changelogUrl": "https://www.curseforge.com/minecraft/mc-mods/distant-horizons/files/8389148"
    },
    {
      "version": "8037637",
      "changelogUrl": "https://www.curseforge.com/minecraft/mc-mods/distant-horizons/files/8037637"
    }
  ],
  "homepage": "https://www.curseforge.com/minecraft/mc-mods/distant-horizons"
}

Versions are CurseForge file IDs (not semver). Use versioning: loose and set maxMajorIncrement: 0 so Renovate does not treat large file ID jumps as forbidden major bumps.
