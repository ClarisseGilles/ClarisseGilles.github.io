# Lithium (Fabric/NeoForge) (NeoForge 1.21.1)

## 8330365

Lithium 0.15.4 for Minecraft 1.21 and 1.21.1 backports a few bug fixes.

Make sure to take a backup of your world before using the mod and please report any bugs and mod compatibility issues at theissue tracker. You can check thedescription of each optimizationand how to disable it when encountering a problem.

Fixes

Fix supporting block movement shortcut not offsetting VoxelShape

Fix double inventory related inventory invalidation issues

Avoid crashing when modded levels with broken registries are created

Fix comparator updates missing for furnaces and brewing stands
